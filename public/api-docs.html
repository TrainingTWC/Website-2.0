Data Export API

Single authenticated endpoint that snapshots every superadmin-visible table in the Third Wave Coffee Convex backend. Designed for external analytics, BI dashboards, and data pipeline ingestion.

Overview

The export API is a single HTTP GET endpoint hosted on Convex's edge infrastructure. One call returns up to 16 datasets in a single JSON payload — no pagination tokens, no GraphQL schemas, no SDK required.

Base URL:  https://watchful-cormorant-351.convex.site
All requests are HTTPS. CORS headers are included so browser-side calls also work.

FormatJSON

Authentication

Every request must include an Authorization header with a valid API key as a Bearer token.

# Required header on every request
Authorization: Bearer twc_live_<64-hex-chars>

Key format

Keys follow the pattern twc_live_ followed by 64 lowercase hexadecimal characters (32 random bytes), giving a total of 73 characters.

twc_live_a3f9c2b1e8d74f0a5b6c2d9e1f4a7b3c2d5e8f1a0b4c7d2e5f8a1b3c6d9e2f5

Security model

Only the SHA-256 hash of each key is stored in the database. The raw key is displayed exactly once at creation and cannot be recovered — treat it like a password.

⚠ Never embed a key in client-side JavaScript. Call the export endpoint from your backend server or a secure environment. The endpoint returns PII (customer names, phone numbers, emails).

Creating an API Key

API keys are managed entirely within the Super Admin panel — no CLI or Convex dashboard access needed.

  1. Navigate to thirdwavecoffee.prismintelligence.in/admin?role=superadmin
  2. Open the Governance → API Keys sidebar section
  3. Click New key, enter a descriptive label (e.g. Analytics App)
  4. Click Create — the full key appears highlighted in green
  5. Copy it immediately. It will not be shown again.

To revoke a key, find it in the list and click Revoke. Revoked keys are rejected on the next request.

GET /api/v1/export

GET https://watchful-cormorant-351.convex.site/api/v1/export

Returns a full snapshot of all exportable data. All 16 datasets are fetched in parallel server-side and returned in a single response body.

Query Parameters

ParameterTypeRequiredDefaultDescription
from number Optional 0 Unix milliseconds. All time-series tables return records created/updated at or after this timestamp. Reference tables (products, categories, admins, etc.) always return their full set regardless.

Incremental sync: Pass the generatedAt value from the previous response to receive only records newer than your last sync.
Default is all-time (from=0). Your first call always returns the full historical dataset. For subsequent calls, pass generatedAt from the previous response as ?from= to fetch only new records.

Limits & Pagination

There is no explicit rate limit enforced by the API, but Convex enforces its own function execution limits. The recommended polling interval for an analytics app is no more than once per minute.

If you hit a row cap (e.g. exactly 5 000 orders returned), there may be older records not included. Use ?from=<oldest _creationTime in the batch> on the next call to page backwards, or reduce your sync interval so batches stay under the cap.

Incremental Sync Pattern

// First call — fetch all historical data
const r1 = await fetch("https://watchful-cormorant-351.convex.site/api/v1/export", {
  headers: { Authorization: `Bearer ${API_KEY}` }
});
const d1 = await r1.json();
let cursor = d1.generatedAt;   // save this

// Subsequent calls — only new records since last sync
const r2 = await fetch(
  `https://watchful-cormorant-351.convex.site/api/v1/export?from=${cursor}`,
  { headers: { Authorization: `Bearer ${API_KEY}` } }
);
const d2 = await r2.json();
cursor = d2.generatedAt;   // advance cursor

Code Examples

const API_KEY = process.env.TWC_API_KEY;
const BASE    = "https://watchful-cormorant-351.convex.site/api/v1/export";

async function fetchAll() {
  const res = await fetch(BASE, {
    headers: { Authorization: `Bearer ${API_KEY}` },
  });
  if (!res.ok) throw new Error(`API error ${res.status}`);
  return res.json();
}

async function fetchDelta(fromMs) {
  const res = await fetch(`${BASE}?from=${fromMs}`, {
    headers: { Authorization: `Bearer ${API_KEY}` },
  });
  return res.json();
}

// Usage
const snap = await fetchAll();
console.log("Products:", snap.data.products.length);
console.log("Orders:",   snap.data.orders.length);
console.log("Counts:",   snap.counts);

import os, requests

API_KEY = os.environ["TWC_API_KEY"]
BASE    = "https://watchful-cormorant-351.convex.site/api/v1/export"

def fetch_all():
    r = requests.get(BASE, headers={"Authorization": f"Bearer {API_KEY}"})
    r.raise_for_status()
    return r.json()

def fetch_delta(from_ms: int):
    r = requests.get(BASE, params={"from": from_ms},
                     headers={"Authorization": f"Bearer {API_KEY}"})
    r.raise_for_status()
    return r.json()

snap = fetch_all()
print("Products:", len(snap["data"]["products"]))
print("Orders  :", len(snap["data"]["orders"]))
print("Counts  :", snap["counts"])

# Incremental — persist cursor between runs
cursor = snap["generatedAt"]
delta  = fetch_delta(cursor)
new_orders = delta["data"]["orders"]
