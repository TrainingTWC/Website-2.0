What This Platform Is

One system. Every layer of the business.

Customer Storefront

Premium e-commerce experience with 3D product viewer, AI-powered coffee match quiz, smooth-scroll storytelling, and Razorpay checkout.

Real-Time Operations Hub

Admin dashboard with live inventory, order management, customer lookup, editorial CMS, discount engine, and full funnel analytics.

AI-First Architecture

Mistral AI for coffee recommendations and customer support. Responses are cached so repeat questions cost nothing. Usage is rate-limited to prevent abuse.

Behavioural Analytics

26+ anonymous shopper actions tracked per session — where people drop off, which carts are abandoned, which payment methods fail, and which UI elements confuse users.

Security-First Design

Two-factor login for all admins, tamper-proof order IDs, locked-down login with automatic account protection after repeated failures.

Globally Fast

The website is pre-built and served as static files from Cloudflare's global network. No server boots up when a user visits. Pages load in under 2 seconds anywhere in the world.

Product Features

Every feature, documented.

Customer-Facing Features

Homepage Storytelling Experience

Lenis smooth-scroll narrative with animated hero, rotating brand story stats, product showcases, editorial cards, and Flash Sale banners. All copy is live-editable via CMS.

In plain terms: the homepage is a living, scrollable brand story. Marketing can update every word and image without touching a line of code.

Shop — Filterable Product Catalogue

Two-level product taxonomy: Coffee Beans, Easy Coffee Bags, Drinkware, Carry Bags, Keychains, Chocolates & Nuts, Brewing Tools. Filter by roast level, origin, and tags. Live stock status badges.

Product Detail Page + 3D Viewer

Interactive 3D model viewer per product. Flavor note chips, roast level indicator, origin badge, rating, and AI-matched cross-sell suggestions.

In plain terms: customers can rotate and inspect products in 3D before buying, the same way you'd pick up a bag in-store.

AI BrewMatch Quiz

Multi-step preference quiz (brew method, taste profile, occasion). An AI model picks the best-matched products with a personalised explanation. Identical answers are cached — repeat quiz runs cost zero in API fees.

In plain terms: a customer says how they like their coffee, and the platform recommends the right product — like a knowledgeable barista, but available 24/7.

Smart Cart with Order Limits

The cart automatically enforces a per-product order limit based on current stock and recent sales velocity. First-time buyers get a slightly higher limit to encourage trial; frequent bulk buyers get a lower one to keep stock available for everyone.

In plain terms: no single customer can clear out stock on a popular product. The limit adjusts itself every 15 minutes based on how fast items are selling.

Discount Engine

Four offer types: coupon (manual code entry), cashback (badge display), auto (no code needed), free shipping. Supports percentage or flat discounts, first-order-only restriction, minimum cart value, savings cap, expiry date, and total usage limits.

In plain terms: marketing can create any kind of offer with guardrails — a code that works only once per person, only on first orders, only above a certain cart value, and only until a set date.

Checkout + Razorpay Payments

Full address form with validation. Prices are recalculated on the server at payment time — the customer cannot manipulate the amount. Supports UPI, cards, net banking, EMI, and wallets. Discount is re-validated at submit.

In plain terms: the server always decides the final price. Nothing the customer does on their browser can change what they actually get charged.

Order Tracking Page

Customer self-service order lookup by order ID. Live status timeline. AI-powered support chat that knows the customer's specific order — answers questions about status, items, and shipping without a human agent.

In plain terms: customers get instant answers about their order from an AI that already knows their details — reducing support load on the team.

Journal / Editorial Hub

Content feed of five post types: Flash Sale, Product Launch, Café News, Brand Story, Champion Feature. Linked to products and discounts. Draft / scheduled / published workflow with expiry support.

About & Third Circle Pages

Brand narrative with stats, team story, and sourcing journey. Third Circle: exclusive community section with its own route and content.

Interactive Map (Leaflet)

Sourcing origin map using React Leaflet — shows coffee growing regions linked to catalog origins.

OTP Login (Customer Phone)

Convex Auth OTP flow for customers wanting order history. Anonymous shopping works without any login — OTP is only required for returning user features.

Platform & Operations Features

Admin Dashboard — Overview

Instant KPIs: total revenue, total orders, completed/pending/cancelled breakdown, average order value. All numbers update in real time as orders come in — no page refresh needed.

In plain terms: the moment a customer places an order, the revenue counter on the admin screen ticks up automatically.

Inventory Management

Add, edit, and delete products. Upload images and 3D models. Track stock quantities with automatic low-stock flagging. The system recalculates order limits every 15 minutes based on recent sales.

Order Management

Full order lifecycle: view, filter by status, mark confirmed/shipped/delivered/cancelled, add internal notes. Look up any customer by phone or email. Revenue figures update the moment a status changes.

Editorial CMS

Write and publish posts: Flash Sales, Product Launches, Cafe News, Brand Stories, Champion Features. Schedule posts to go live at a future date and expire automatically. Link any post to a product or discount code.

Home Content CMS

Edit every section of the homepage — headlines, body text, stats, images, and story slides — directly from the admin panel. Changes go live instantly with no code deployment required.

In plain terms: marketing can refresh the entire homepage look and feel in minutes, without involving a developer.

Discount Code Manager

Create/edit/deactivate discount codes. All four offer kinds. Preview computed savings before saving. Usage tracking in real time.

Funnel Analytics Dashboard

10-section dashboard: KPI tiles, funnel bar chart, dropout hotspots, abandoned carts (with ₹ value), payment funnel, device breakdown, rage/dead click counts, client error feed, daily trends, and UTM attribution.

Page View Analytics

Daily summary with total views, unique sessions, per-path breakdown, geo heatmap (country + city), GPS vs IP geo source split, and avg time on page.

Real-User Performance Monitoring

Five Google-standard page speed metrics are measured on every visitor's actual device and stored — split by device tier (budget phone, mid-range, high-end). This shows whether the site is genuinely fast for the customers using it, not just fast on a developer's laptop.

Audit Log

Immutable server-side log of every admin action: product edits, order updates, admin invites, discount changes. Tagged with admin user ID + email + timestamp.

Admin Access Control & Two-Factor Login

Every admin has a role that restricts exactly which sections they can see. Login requires both a password and a one-time code sent to the admin's email. Sessions expire after 30 minutes. The account locks automatically after repeated wrong attempts.

In plain terms: a content writer can log in and edit posts but will never see revenue figures or customer data — those sections simply don't appear for them.

API Key Management

Admin-controlled API keys for external integrations. Key scoping and revocation capabilities.

Customer Experience

The complete user journey.

Discovery

Shopper arrives via organic search, social media, or a campaign link. The channel they came from (Instagram, Google, email, etc.) is recorded on their very first action and remembered for the rest of their visit.

Landing & Brand Immersion

Homepage loads in under 2 seconds from Cloudflare's nearest server. The scrollable brand narrative plays — hero, story stats, product teasers, editorial cards, flash-sale banners. The visit is recorded, starting the funnel.

Explore — Shop or BrewMatch

Path A — Shop: User filters by type, roast, origin, and browses. Path B — BrewMatch: User takes the 5-step AI quiz and gets personalised product picks with an explanation. Visiting a product page is recorded as a funnel event.

Product Detail

3D model viewer loads. User reviews flavor notes, origin, roast level, and stock status. The order limit for this product is already pre-calculated and ready — the customer never sees a delay.

Add to Cart

Adding to cart is recorded as a funnel event. A cart snapshot is saved — item list, subtotal, and the page they were on. Quantity changes and removals are also tracked to detect friction.

Discount Code

User enters a coupon (or an auto-discount applies). The server checks: is the code still valid, has the usage limit been hit, does the cart meet the minimum value, and is this actually the customer's first order? Savings preview shown before confirm.

Cart Review

Opening the cart panel is recorded as a funnel event. If the user goes idle for more than 30 minutes, the cart is flagged as abandoned. Abandoned carts that have a phone or email (entered at checkout) are eligible for recovery outreach.

Checkout

Starting checkout is recorded. User fills in name, phone, email, and delivery address. If form validation fails, the failing fields are recorded — this shows which fields are causing the most friction. Once submitted, the contact details are attached to the cart snapshot so it becomes recoverable.

Payment

Payment method selection is recorded. When the customer taps "Place Order", the server recalculates the total from the database and re-validates the discount — then creates the Razorpay payment. The Razorpay modal opens for the customer to complete payment.

Order Confirmed

On success, the order confirmation event fires. The cart is removed from the abandoned cart list. The order gets a unique ID (TWC-XXXXXXXX). Revenue counters and order counts update immediately across the entire admin dashboard.

Order Tracking

Customer visits the orders page, enters their order ID, and sees the live status. They can ask the AI support agent anything about their order — it knows their order details and responds in plain language.

Return & Re-engagement

The anonymous browser ID persists across visits, so returning customers are recognised and stitched to their previous funnel history. Flash sales and new product posts in the journal drive repeat visits.

Technology

Why every tool was chosen.

The core philosophy: Every technology choice eliminates a category of operational burden. We have no servers to manage, no deployment pipelines to babysit, no CDN to configure, and no database to scale. The team ships features, not infrastructure.

In plain terms: there is no machine sitting in a data centre that we pay for and worry about. The whole platform runs on managed cloud services that scale automatically and charge only for what is used.

Next.js 15.3
React 19 · TypeScript 5.8
Frontend

Static export means the entire storefront ships as flat HTML/JS/CSS files. No server required. No cold starts. No scaling knobs to turn. Cloudflare serves files from the nearest global edge location at zero infrastructure cost.

Why not something simpler? Next.js gives us file-based routing, built-in image optimisation, and the ability to load heavy components (3D viewer, animations) only when needed — critical for users on budget Android devices.

In plain terms: the website is like a PDF — it is pre-built and just delivered. It does not need a running computer to serve it. This is why it loads so fast and never goes down.

Convex
v1.38 · Real-time serverless BaaS
Backend

Convex is the entire backend: database, server logic, file storage, authentication, scheduled jobs, and live data sync — all in one service. Why Convex over Firebase or Supabase?

  • The admin dashboard updates live the moment an order arrives — no page refresh, no polling
  • Revenue counters update atomically when an order status changes — no chance of double-counting
  • Server functions can call Mistral, Razorpay, and Resend without needing a separate API server
  • Product images and post covers are stored and served via CDN automatically
  • Scheduled jobs (like the 15-min order limit refresh) are a few lines of code, not a separate service

In plain terms: Convex is the brain of the operation — it holds all the data and runs all the business logic. When the admin marks an order as delivered, Convex updates the revenue counter, the customer's tracking page, and the audit log — all at once, instantly.

Mistral AI
mistral-small-2603 · Hybrid Reasoning
AI

Two AI features use Mistral: BrewMatch (quiz recommendations) and Order Support Chat. The model chosen is good at following complex multi-step reasoning — like matching a taste preference to a specific product across 50+ catalog items — at a low cost per use.

Cost control is built-in: Every BrewMatch result is fingerprinted by the user's answers. If two people give identical answers, the second person gets the cached result instantly — no AI call, zero cost. The cache automatically clears whenever the underlying prompts are changed.

Abuse protection (two layers): A maximum of 5 AI calls per user per 15-minute window. A backup limiter kicks in if the primary one is unavailable. Neither can be bypassed.

In plain terms: the AI features cost almost nothing to run at scale because repeat questions are served from a cache rather than calling the AI again. And no one can run up the bill by spamming the quiz.

Tailwind CSS v4
+ Motion (Framer Motion 12)
Frontend

Tailwind handles all visual styling with minimal CSS output. Motion handles all animations — but only using properties the browser can animate on the GPU (movement and transparency), never ones that require recalculating layout.

Why this matters: Animations only start when an element scrolls into view. Users on budget phones get smooth animations, not janky ones.

In plain terms: the visual polish is engineered to be smooth on a ₹8,000 Android, not just on a MacBook.

React Three Fiber + Three.js
R3F v9 · @react-three/drei v10
Frontend

Powers the interactive 3D product viewer. Models load in WebGL — the same technology used in browser-based games — so products can be rotated and examined from any angle.

The 3D code is loaded separately, only when the user visits a product page. It never adds weight to the homepage load.

In plain terms: the homepage loads fast because the heavy 3D code only downloads when a customer actually opens a product detail page.

Lenis
v1.3 · Smooth scroll
Frontend

Lenis gives the page a smooth, momentum-based scroll feel — the same technique used by luxury and editorial brand websites globally. It works in harmony with the scroll-triggered animations so the whole experience feels cohesive.

In plain terms: this is the library responsible for that premium, buttery scroll feeling when you move through the homepage.

Razorpay
Payment Gateway · India-first
Payments

The only viable choice for an Indian D2C brand — supports UPI (GPay, PhonePe, Paytm), Net Banking, Cards, EMI, and Wallets. Payment references are stored on every order for finance reconciliation. The server always recomputes the final price before creating the payment — the customer's browser cannot manipulate what they get charged.

In plain terms: Razorpay handles the money. The customer pays, Razorpay confirms it, and we get the order. No card numbers or payment details ever touch our servers.

Convex Auth + OTP 2FA
@convex-dev/auth v0.0.92
Security

Handles all user authentication. The admin two-factor layer sits on top: every login requires a 6-digit code sent by email. The code itself is never stored — only a one-way encrypted fingerprint of it is saved. Even if the database were compromised, active codes could not be recovered. Sessions are verified on the server on every page — not just at login.

In plain terms: knowing someone's admin password is not enough to get in. You also need access to their email inbox.

Upstash Redis
REST API · Serverless Redis
Infra

A fast in-memory counter service used to track how many AI calls a user has made in the last 15 minutes. Works via a simple HTTP call — no persistent connection needed. If this service is ever unavailable, a backup counter inside the database takes over automatically.

In plain terms: this is the bouncer that prevents any single user from spamming the AI quiz and running up costs. There are two bouncers, so if one is out sick, the other steps in.

GitHub Pages + Cloudflare
CDN · Worker Proxy
Infra

Zero server to manage. The built website files are pushed to GitHub Pages automatically when code is merged. Cloudflare sits in front for: custom domain, HTTPS, global caching, security headers, and a lightweight serverless function for any logic that needs to run server-side.

In plain terms: deploying a code change is one git push. The whole pipeline — build, test, deploy — runs automatically in about 3 minutes with no human involvement.

PostHog
v1.375 · Product Analytics
Analytics

PostHog captures session recordings, heatmaps, and retention cohorts as a second analytics layer. The two systems serve different purposes: PostHog is for marketing and UX exploration — watching how users navigate, where they click, who comes back. The custom analytics built into the platform is for real-time operational decisions — abandoned carts, payment failures, live error monitoring.

In plain terms: PostHog is like a CCTV recording of the shop floor. The custom analytics is the ops dashboard telling us right now what is broken and what money is being left on the table.

web-vitals + BlurHash
v4.2 · RUM Telemetry
Performance

Google's standard page speed library measures five performance metrics on every real visitor's device and stores them in the database — tagged by device tier so we can tell if a change made things slower specifically for budget-phone users. BlurHash means product images always show a blurred colour preview instantly while the real image loads — they never appear as a blank white box.

In plain terms: we measure page speed on real customers' phones, not just in a lab. If a code change slows things down for someone on a ₹6,000 handset, we see it in the data before customers complain.

Resend
Transactional Email
Email

Sends the admin two-factor login codes via email from a verified domain. High deliverability means OTP codes reliably reach inboxes and do not land in spam. Also used for future customer order confirmation and shipping update emails.

Traffic Architecture — How Requests Flow

Visitor's Browser

The React app runs here. After the first load, all page navigation is instant — no full reload needed.

→

Cloudflare (Global Edge)

Serves files from the nearest data centre to the visitor. Adds security headers. Responds in under 50ms.

→

GitHub Pages (Origin)

Stores the master copy of the built website files. Free, auto-updated on every code push.

→

Convex (Database + Logic)

All live data — orders, products, analytics — lives here. Changes push to all connected screens instantly.

Why this scales: The storefront has no backend server. 10 users or 10,000 concurrent users get the same sub-50ms static file response from Cloudflare's edge. Convex handles data queries — its serverless functions auto-scale horizontally. The only "scale concern" is Convex function throughput, which is metered per-project and scales with usage automatically.

Database Design for Speed

Indexed Reads — Never Full Scans

Every query uses an explicit Convex index: by_status, by_orderId, by_customerPhone, by_date, by_anon. No table scans in production queries.

Materialized Aggregates

Revenue KPIs stored in orderSummary singleton — updated atomically on every order mutation. Dashboard loads instantly without ever scanning orders.

Daily Summary Rollups

pageViewDailySummary is a pre-aggregated counter updated on every page view. Raw pageViews rows are cleaned up nightly by cron.

AI Response Cache

SHA-256 keyed cache in aiCache table. Identical quiz answers return a cached recommendation — no Mistral API call, no latency, no cost.

3-Second Rate Limiter

Page view mutations check for a recent insert from the same session before writing — prevents analytics spam from rapid navigation.

Event Batch Writes

trackBatch writes up to 50 behavioural events in a single Convex mutation call. 50× reduction in round-trips vs. event-per-mutation.

Data Intelligence

Every data point, every surface.

Privacy-first design: All browsing and clicking behaviour is tracked anonymously. No name, phone, or email is ever attached to the event data — shoppers are identified only by a random ID generated in their browser. Contact details are collected only when a customer explicitly fills in the checkout form and places an order.

In plain terms: we know that "someone" added a product to their cart and then left — but we do not know who that person is until they choose to tell us by completing a purchase.

Security

Built secure by design.

Every security measure has a tracking code (e.g. H-02, M-01) that is referenced directly in the source code. This means any security control can be traced to the exact line of code that implements it — making audits straightforward.

In plain terms: security is not an afterthought. Every known attack vector has a named defence, and that defence is documented inside the code itself.

H-02

Cryptographically Random Order IDs

Order IDs are generated using a cryptographically secure random number generator — not a predictable one. This prevents anyone from guessing other customers' order IDs by incrementing numbers.

M-01

Analytics Input Limits

All data sent by the browser to the analytics system is capped at a maximum length before being stored. This prevents a malicious user from flooding the database with junk data by sending oversized payloads.

M-03

AI Prompt Injection Protection

Customer quiz answers and the system's own instructions are sent to the AI in separate, isolated message slots. A customer cannot write something in the quiz that tricks the AI into ignoring its instructions or revealing internal data.

In plain terms: the AI cannot be manipulated by a customer typing something clever into the quiz.

XSS-03

Support Chat Length Cap

Customer messages in the AI support chat are capped at 500 characters before being sent to the AI. Order details (trusted) and the customer's question (untrusted) are kept in separate message slots so one cannot contaminate the other.

OTP-01

Login Codes Never Stored in Plain Text

The 6-digit login code is converted to an irreversible fingerprint before being saved. Even if the database were fully exposed, no attacker could recover the actual codes.

AUTH-01

Automatic Account Lockout

5 wrong passwords locks the account for 15 minutes. A maximum of 3 login codes can be sent per 15-minute window. 5 wrong code guesses invalidates the code entirely. Each limit is independent.

AUTH-02

Server-Side Session Verification

Admin sessions are checked against the server on every single page load — not just at login. An attacker who modifies their browser's local storage to fake a session will be rejected immediately.

In plain terms: you cannot break into the admin panel by tampering with your browser. The server checks every page access independently.

TELEMETRY-FLOOD-01

Analytics Flood Protection

A maximum of 50 events can be sent in one batch. Each field has a size limit. Events over the limit are silently trimmed rather than causing an error — so a misbehaving browser never breaks itself or the analytics system.

EDGE-01

Two-Layer AI Usage Limits

Maximum 5 AI recommendation calls per user per 15 minutes, enforced by two independent systems. Neither can be bypassed on its own. Prevents a malicious user from running up AI costs by automating quiz submissions.

DISC-FIRST-ORDER-03

First-Order Discount Anti-Abuse

"First order only" discounts are validated against both the customer's phone number and email address. Creating a new email to reuse the discount while keeping the same phone number is blocked — and vice versa.

HTTP Headers

Browser Security Headers

The site cannot be embedded inside another website (clickjacking protection). The browser is prevented from guessing file types (MIME sniffing protection). The camera, microphone, and location are blocked at the browser level unless explicitly granted by the user.
