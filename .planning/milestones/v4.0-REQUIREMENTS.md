## Requirements

### Editorial Content (Data Layer)

- [x] **EDI-01**: `posts` Convex table with 5 content types
- [x] **EDI-02**: Post fields (type, headline, body, coverImage, status, publishAt, expiresAt, linkedProductId)
- [x] **EDI-03**: Flash-sale posts reference `discountId`
- [x] **EDI-04**: Champion posts with personName, personRole, personStory
- [x] **EDI-05**: `convex/posts.ts` with listPublished, getPost, createPost, updatePost, deletePost

### Discounts

- [x] **OFF-01**: `discounts` table (code, type, amount, firstOrderOnly, expiresAt, maxUses, usageCount)
- [x] **OFF-02**: `validateDiscount` query with eligibility response (valid/reason/type/amount)
- [x] **OFF-03**: `claimDiscount` mutation atomically increments usageCount
- [x] **OFF-04**: Discount code stored on order record at submit time
- [~] **OFF-05**: First-order-only validation — *partial: mechanism exists via by_customerPhone index in validateDiscount; never invoked with real phone/email (claim step passes empty string, submitOrder skips check)*

### Claim Offer UX

- [x] **OFF-06**: Glassmorphism "Claim Offer" button on flash-sale cards
- [x] **OFF-07**: Click → claimDiscount → toast → twc_active_discount localStorage
- [x] **OFF-08**: One active discount at a time with replace confirmation
- [x] **OFF-09**: Active discount cleared from localStorage on order submission

### Magazine Editorial Hub (Frontend)

- [x] **HUB-01**: `?page=editorial` with full-bleed hero
- [x] **HUB-02**: Asymmetric magazine grid (Monocle/Kinfolk aesthetic)
- [x] **HUB-03**: Category filter pills (All | Offers | News | Stories | Champions)
- [x] **HUB-04**: Live countdown timer on flash-sale cards
- [x] **HUB-05**: Product-launch cards link to product detail page
- [x] **HUB-06**: Brand-story/café-news cards open full post detail view
- [x] **HUB-07**: Champions band with photo, name, role, favourite product
- [x] **HUB-08**: "Journal"/"Third Circle" nav link in header/footer

### Admin CMS

- [x] **CMS-03**: Post creation/edit form with all fields + cover image upload
