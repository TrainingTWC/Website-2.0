<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage → CartContext | Client can modify twc_cart before React reads it |
| localStorage → DiscountContext | Client can modify twc_active_discount before React reads it |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | CartContext localStorage read | accept | Cart items are product IDs + quantities only — no prices stored client-side. Prices always fetched from Convex at checkout. Malformed JSON silently ignored in try/catch. |
| T-02-02 | Tampering | DiscountContext localStorage read | accept | Server re-validates discount code in `submitOrder` (already exists from v4.0). Client-side discount display is non-authoritative — UI only. JSON parse errors silently return null. |
| T-02-03 | Information Disclosure | localStorage keys | accept | twc_cart and twc_active_discount contain no PII — only product IDs, qty, and a discount code string. Low sensitivity. |
| T-02-04 | Spoofing | CartPanelProvider products query | accept | Products loaded via useProducts() (Convex query) — read-only, no mutation. |
</threat_model>
