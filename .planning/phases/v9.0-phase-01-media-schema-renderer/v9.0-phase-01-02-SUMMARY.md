# v9.0 Phase 01 / Plan 02 — Media Renderer Components

## What shipped

Four client components implementing slot-driven, kind-switching media rendering:

| File | Role |
|------|------|
| `src/components/media/BlurhashImage.tsx` | `<img>` with blurhash LQIP placeholder + fade-in |
| `src/components/media/LottiePlayer.tsx` | IO-gated Lottie player, dynamic import of `lottie-react`, reduced-motion-aware |
| `src/components/media/GLBViewer.tsx` | R3F Canvas + `useGLTF`, full Canvas teardown when offscreen |
| `src/components/StudioMedia.tsx` | Root renderer — reads `api.media.getActive`, branches on kind, tier-gates video |

## Behavior contract

- `useQuery(api.media.getActive, { slot, slotKey })` is the sole data source.
- Returns `null` when query is loading or no published row exists → no broken-image flash.
- Branches on `kind`: image | gif | video | lottie | glb.
- Video: autoplay only when `perfTier === "high" && !reducedMotion`; otherwise renders poster (or main URL) as still via `BlurhashImage`. IntersectionObserver play/pause when autoplay is allowed.
- GIF: when `reducedMotion`, renders poster still if available; otherwise renders gif via `<img>`.
- Lottie: gates `loop` and `autoplay` on `!prefersReducedMotion`; pauses when offscreen.
- GLB: Canvas unmounts entirely when offscreen — releases WebGL context.
