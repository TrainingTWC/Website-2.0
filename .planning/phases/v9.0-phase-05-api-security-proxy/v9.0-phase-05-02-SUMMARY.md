# Phase v9.0-phase-05 — Plan 02 Summary

## What Was Built

Created two Next.js API proxy routes and migrated client components off direct Convex action/mutation calls.

### Changes

**`app/api/orders/route.ts`** (new)
- `POST /api/orders` — proxies `orders.submitOrder` Convex mutation
- Rate limit: 20 req/min per IP via `checkRateLimit`
- Manual validation: customer.name (non-empty), customer.phone (`/^\d{10}$/`), customer.email (@ + dot-after-@), address.line1/city/state (non-empty), address.pincode (`/^\d{6}$/`), items (non-empty array with productId/name/qty/price), subtotal (positive number)
- Forwards validated args to `convexServer.mutation(convexApi.orders.submitOrder, ...)`
- Returns `Response.json(result)` on success; `{ error: err.message }` with status 500 on Convex error
- Convex errors (including discount-related ConvexError) are passed through as HTTP 500 so CheckoutPage retry logic continues to work

**`app/api/recommendations/route.ts`** (new)
- `POST /api/recommendations` — proxies `brewingRecipe` and `flavoredDrink` Convex actions
- Rate limit: 10 req/min per IP (AI calls consume OpenAI quota)
- Discriminated union on `kind: "brew" | "drink"` with per-kind validation
- `kind: "brew"`: requires method, strength (non-empty), dose, ratio (positive numbers)
- `kind: "drink"`: requires drinkStyle, flavorAdd, milk, temperature, size (non-empty)
- Forwards to respective `convexServer.action(...)` call; strips `kind` field from Convex payload

**`src/components/CheckoutPage.tsx`** (modified)
- Removed `import { useMutation } from "convex/react"`
- Removed `import { api } from "../../convex/_generated/api"`
- Removed `const submitOrder = useMutation(api.orders.submitOrder)`
- `doSubmit()` now calls `fetch("/api/orders", { method: "POST", ... })` and throws on `!res.ok`
- Discount retry logic (outer try/catch in handleSubmit), `onOrderCreated(result.orderId)`, and all analytics unchanged

**`src/components/BrewingStudio.tsx`** (modified)
- Removed `import { useAction } from "convex/react"`
- Removed `import { api } from "../../convex/_generated/api"`
- Removed `const generateBrew = useAction(...)` and `const generateCraft = useAction(...)`
- `requestBrewRecipe()` now calls `fetch("/api/recommendations", { kind: "brew", ... })`
- `requestCraftRecipe()` now calls `fetch("/api/recommendations", { kind: "drink", ... })`
- Result handling (`if (result.ok)`, error state) unchanged

## Security Model

| Boundary | Protection |
|----------|------------|
| Browser → Next.js API | HTTPS, rate limiting per IP, input validation |
| Next.js API → Convex | Server-side only; Convex URL/credentials never in client bundle |
| Convex actions (AI) | Proxied via /api/recommendations; client never calls Convex directly |
| Convex mutations (orders) | Proxied via /api/orders; browser cannot bypass proxy to call submitOrder |
