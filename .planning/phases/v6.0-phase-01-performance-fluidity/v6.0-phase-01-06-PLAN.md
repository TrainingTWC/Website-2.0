<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 1: User UAT on 8 GB RAM laptop</name>
  <what-built>
    All performance changes from plans 01–05: tier-aware perf hook, fixed Lenis dispatch, consolidated Cinematic scroll, tier-gated 3D/effects, image hygiene, LazyMotion split.
  </what-built>
  <how-to-verify>
    On an 8 GB RAM Windows laptop (Chrome stable, fresh profile, no extensions interfering), run through this checklist and record the result in `.planning/phases/v6.0-phase-01-performance-fluidity/UAT.md` (the agent will create the file scaffold; user fills in numbers + screenshots).

    1. **Lighthouse desktop** on `https://thirdwavecoffee.prismintelligence.in/`:
       - DevTools → Lighthouse → Desktop → Performance only → Analyze.
       - Record: Performance score, FCP, LCP, INP, CLS, TBT.
       - Repeat for `/shop`, `/products/<any-slug>`.
       - Pass threshold: Performance ≥ 95 on each.

    2. **Lighthouse mobile** (same URLs, "Mobile" mode in Lighthouse).
       - Pass threshold: Performance ≥ 90.

    3. **Home scroll FPS** on `/`:
       - DevTools → Performance → Record → scroll smoothly from top to bottom over ~10 s → Stop.
       - Read FPS chart at the top of the recording. Pass threshold: average ≥ 55 fps, no segment below 30 fps for more than 1 frame.

    4. **INP**:
       - Open cart panel via header cart button. Add to cart from /shop. Open/close discount banner.
       - With Performance recording on, watch for "Long Task" markers > 200 ms during these interactions. Pass: none.

    5. **Reduced-motion check**:
       - DevTools → Rendering → Emulate CSS media feature `prefers-reduced-motion: reduce`. Reload `/`.
       - Verify: no Lenis class on `<html>`, ChapterDeck is static (no transform), MagneticCursor gone, GalaxySweep gone, ProductHero3D pages show static images.

    6. **Low-RAM emulation** (proxy for `tier=low`):
       - DevTools → Console → `Object.defineProperty(navigator, 'deviceMemory', { get: () => 2 })` → reload.
       - Verify: BestsellerCarousel shows the flat strip (not 3D).

    7. **Web vitals telemetry**:
       - Open Convex dashboard → `webVitals` table → confirm rows are appearing after fresh page loads.

    Mark each row in UAT.md as PASS or FAIL with the captured number. If any row fails, file a follow-up task and re-run.
  </how-to-verify>
  <resume-signal>Type "approved" once UAT.md is signed off, or paste failing rows to triage.</resume-signal>
</task>
