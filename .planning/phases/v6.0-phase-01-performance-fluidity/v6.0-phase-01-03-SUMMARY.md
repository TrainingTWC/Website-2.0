# Plan v6.0-phase-01-03 — Cinematic Single-Scroll + Tier Gate

## What shipped

- **`ChapterDeck`** — now owns the **only** `useScroll` for the deck. Wraps all children in a `deckRef` div, computes one `scrollYProgress`, and passes it plus the per-chapter slice `[i/N, (i+1)/N]` into every `ChapterReveal`. Net: N subscriptions collapsed into 1.
- **`ChapterReveal`** — no longer subscribes its own scroll. New required props `scrollProgress`, `localStart`, `localEnd`. All parallax transforms derived via `useTransform(source, [...local-mapped breakpoints...], [...])`.
- **Tier-aware static fallback** — when `reducedMotion || tier === "low"`, the component skips all motion: wordmark, product, and copy render with `transform: "none"` and `opacity: 1`. `MacroBeam` light-sweep is not mounted. No `useTransform` reads contribute layout work.
- **IO-driven willChange** — `IntersectionObserver` with `rootMargin: "100% 0%"` toggles `willChange: "transform" ↔ "auto"` so off-screen chapters don't keep a composited layer pinned.
- **MacroBeam progress** now derives from the same shared source (slice-local 0→1 via `useTransform`).

## Verification

- `Select-String -Path src/components/Cinematic.tsx -Pattern "useScroll\("` returns exactly **3 calls** — `CinematicHero`, `CurtainTransition`, `ChapterDeck`. **`ChapterReveal` scope: zero.** ✅
- TypeScript clean.
- `npm run build` exits 0.

## Behavioral notes

- The visual is intentionally near-identical to the previous per-chapter scroll: each slice's start/end roughly matches the old `["start end","end start"]` behavior. Minor differences are within the noise floor of human scroll perception.
- Standalone use of `ChapterReveal` outside `ChapterDeck` is now a type error (props are required). This is intentional — the only caller is `ChapterDeck`.
