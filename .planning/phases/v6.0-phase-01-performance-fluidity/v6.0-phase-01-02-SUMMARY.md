# Plan v6.0-phase-01-02 — SmoothScroll Tier-Gating

## What shipped

- `src/components/SmoothScroll.tsx` — Now consumes `usePerfMode()`. On `reducedMotion || tier === "low"` it strips the `.lenis` classes and returns native scroll (no rAF loop, no Lenis instance). Tier-aware tuning: `mid` → `lerp: 0.10, syncTouch: false`; `high` → `lerp: 0.08, syncTouch: true`. Effect deps `[tier, reducedMotion]` so users that toggle reduced-motion get the new behavior live.
- **D-05 critical fix**: removed `window.dispatchEvent(new Event("scroll"))` from the rAF loop. motion/react's `useScroll` reads the real scroll position natively; the synthetic dispatch was the single largest scroll-fps regression in v5.x.
- `src/index.css` — clarified comment explaining that `html.lenis` rules only apply when Lenis has set the class, so native scroll resumes cleanly when SmoothScroll bails out.

## Requirements satisfied
