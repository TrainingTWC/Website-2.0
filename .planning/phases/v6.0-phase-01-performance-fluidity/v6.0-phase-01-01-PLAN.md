  <files>package.json, src/lib/usePerfTier.ts</files>
  <action>
    Install `web-vitals@^4` as a runtime dependency (`npm install web-vitals@^4`).

    Create `src/lib/usePerfTier.ts`:
    - Export `type PerfTier = "low" | "mid" | "high"`.
    - Export `type PerfSignals = { tier: PerfTier; deviceMemoryGB: number | null; hwConcurrency: number | null; reducedMotion: boolean; estimatedHz: number | null }`.
    - Export `usePerfTier(): PerfSignals`.
    - On first render return `{ tier: "mid", deviceMemoryGB: null, hwConcurrency: null, reducedMotion: false, estimatedHz: null }` (SSR-safe default, per D-01).
    - In `useEffect`:
      1. Read `(navigator as any).deviceMemory` and `navigator.hardwareConcurrency`.
      2. `const reduced = window.matchMedia("(prefers-reduced-motion: reduce)").matches`.
      3. Sample refresh rate: collect 60 rAF deltas, estimate Hz = `1000 / median(delta)`. Bucket to nearest of [60, 90, 120, 144].
      4. Classify tier per D-04: `low` if `reduced || (deviceMemory ?? 8) <= 4 || (hwConcurrency ?? 8) <= 4`; else `high` if `(deviceMemory ?? 0) >= 8 && (hwConcurrency ?? 0) >= 8 && (hz ?? 0) >= 90`; else `mid`.
      5. `setState` with computed signals.
    - Subscribe to `matchMedia("(prefers-reduced-motion: reduce)").addEventListener("change", ...)` and recompute on change.
    - Guard against running twice in StrictMode (use a ref).
  </action>

  </verify>
