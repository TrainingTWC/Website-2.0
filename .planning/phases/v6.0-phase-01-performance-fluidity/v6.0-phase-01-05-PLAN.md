<interfaces>
`SmartImage` already wraps the Next.js image story for the project. Confirm it accepts `priority`, `sizes`, `width`, `height` and `loading` props (or add them).

`motion/react` LazyMotion + domAnimation pattern:
```tsx
import { LazyMotion, domAnimation, m } from "motion/react";

<LazyMotion features={domAnimation} strict>
  <m.div initial={{ opacity: 0 }} animate={{ opacity: 1 }} />
</LazyMotion>
```
With `strict`, using `motion.X` (vs `m.X`) becomes a build-time warning — we accept the warning for now and migrate hotspots in this plan; trailing `motion.` usage continues to work via fallback at runtime (without `strict`).

Static export + GitHub Pages: `images: { unoptimized: true }` is already set (required for static export). `remotePatterns` is still useful so `next/image` accepts the Convex storage host without throwing in dev.
</interfaces>
