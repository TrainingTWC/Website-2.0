# Plan v6.0-phase-01-01 — Adaptive Perf Tier + Web Vitals

## What shipped

- `src/lib/usePerfTier.ts` — SSR-safe `usePerfTier()` hook returning `{ tier, deviceMemoryGB, hwConcurrency, reducedMotion, estimatedHz }`. Defaults to `mid` pre-mount; classifies per CONTEXT D-04 after a 60-frame rAF refresh sample.
- `src/context/PerfModeContext.tsx` — `<PerfModeProvider>` + `usePerfMode()` context. Wraps the app in `app/providers.tsx`.
- `src/lib/webVitals.ts` — `reportWebVitals({ tier, sendToConvex })`. Lazy-imports `web-vitals` v4 so it stays out of the critical path. Dev logs `[vitals]` to console.
- `convex/schema.ts` — new `webVitals` table (name/value/rating/page/userAgent/tier) with `by_name` + `by_page` indexes.
- `convex/webVitals.ts` — `record` mutation + `recent` query (Convex v1 function syntax).
- `src/components/WebVitalsBootstrap.tsx` — Client component sibling under `<PerfModeProvider>` that wires `reportWebVitals` to the Convex mutation. Subscribes once via a ref.
- `app/providers.tsx` — wraps app in `<PerfModeProvider>` inside `ConvexAuthProvider`, mounts `<WebVitalsBootstrap />`.
- `web-vitals@^4` added to `package.json`.

## Verification

- TypeScript: clean across all 7 changed files.
- `npm run build` exits 0. Home (`/`) First Load JS unchanged at 105 kB (web-vitals dynamically imported, not in initial chunk).
- Convex schema validated (no codegen errors).

## Decisions during execution

- Chose a new `webVitals` table over extending `pageViews` (per D-10 agent discretion) to keep analytics indexes lean.
- `usePerfTier` returns `mid` synchronously on SSR/first render — never causes hydration mismatch because the value is stable across SSR + first client render. Real signals arrive in a state update after the 60-frame sample.
- `reducedMotion` is tracked via `matchMedia` and re-classifies on change.
- `WebVitalsBootstrap` mounts even before tier settles; first-paint vitals may be tagged `mid` (the SSR default). That's intentional — it accurately reflects what the user experienced at first paint.

## Requirements satisfied

- PERF-01 — `usePerfTier` returns populated `PerfSignals` post-mount.
- PERF-02 — `usePerfMode()` callable from any client component below `app/providers.tsx`; defaults to `mid` on SSR.
- PERF-03 — Production builds post real metrics into `webVitals`; dev logs them.

## Threat mitigations applied

- T-v6.0-01-01: `convex/webVitals.ts` uses strict `v.union(v.literal(...))` validators on `name`, `rating`, `tier`. Junk payloads rejected at boundary.
- T-v6.0-01-03: `reportWebVitals` subscribes once per page mount; `web-vitals` itself dedupes per session.
