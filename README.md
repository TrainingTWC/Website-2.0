# Third Wave Coffee

Premium specialty coffee e-commerce experience — built by Amritanshu Prasad.

## Tech Stack

- React 19 + TypeScript + Vite
- Convex (backend & real-time database)
- Tailwind CSS v4
- Framer Motion

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `MISTRAL_API_KEY` in [.env.local](.env.local) to your Mistral API key
3. Run the app:
   `npm run dev`
